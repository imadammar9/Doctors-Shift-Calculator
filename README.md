# Tadawa Doctor Staffing Calculator

A single-page calculator that works out how many doctors are needed on each shift (A, B and C) from the expected number of patients, with a financial view of the staffing cost.

## Use it

Open `index.html` in any browser. Everything runs locally in the page; nothing is sent anywhere.

To publish it as a website, turn on GitHub Pages for this repository (Settings, Pages, deploy from the `main` branch) and the calculator will be served from the repository's Pages address.
